## Industry Frameworks

<CardGrid>
    <Card title="FIRST: SBOM and CSAF/VEX Operational Framework" icon="document">
        A comprehensive guide by FIRST on implementing SBOM and CSAF/VEX practices, covering the relationship between static SBOMs and dynamic vulnerability data.
        <a href="https://www.first.org/standards/frameworks/psirts/Consolidated-SBOM-VEX-Operational-Framework.pdf" target="_blank">Download PDF</a>
    </Card>
    <Card title="CISA: SBOM Sharing Primer" icon="document">
        CISA's guide on SBOM sharing roles (Producer, Distributor, Consumer), sharing mechanisms, and best practices for SBOM distribution.
        <a href="https://www.cisa.gov/sites/default/files/2024-05/SBOM%20Sharing%20Primer.pdf" target="_blank">Download PDF</a>
    </Card>
    <Card title="CISA: Types of SBOMs" icon="document">
        Defines the six types of SBOMs (Design, Source, Build, Analyzed, Deployed, Runtime) and their appropriate use across the software lifecycle.
        <a href="https://www.cisa.gov/sites/default/files/2023-04/sbom-types-document-508c.pdf" target="_blank">Download PDF</a>
    </Card>
    <Card title="CSAF: Common Security Advisory Framework" icon="document">
        The OASIS standard for machine-readable security advisories, including VEX profiles for communicating vulnerability exploitability status.
        <a href="https://docs.oasis-open.org/csaf/csaf/v2.0/csaf-v2.0.html" target="_blank">View specification</a>
    </Card>
</CardGrid>

## Community Resources

<CardGrid>
    <Card title="OWASP SCVS" icon="community">
        The OWASP Software Component Verification Standard (SCVS) is a community-driven effort to establish a framework for verifying the security of software components.
        <a href="https://owasp.org/www-project-software-component-verification-standard/" target="_blank">Visit website</a>
    </Card>
    <Card title="SLSA" icon="community">
        Supply-chain Levels for Software Artifacts (SLSA) is a security framework, a check-list of standards and controls to prevent tampering, improve integrity, and secure packages and infrastructure.
        <a href="https://slsa.dev/" target="_blank">Visit website</a>
    </Card>
    <Card title="OpenChain Project" icon="community">
        The OpenChain Project identifies key requirements of a quality open source compliance program to build trust in the open source supply chain.
        <a href="https://www.openchainproject.org/" target="_blank">Visit website</a>
    </Card>
</CardGrid>
