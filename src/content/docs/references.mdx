## Community Resources

<CardGrid>
    <Card title="OWASP SCVS" icon="community">
        The OWASP Software Component Verification Standard (SCVS) is a community-driven effort to establish a framework for verifying the security of software components.
        <a href="https://owasp.org/www-project-software-component-verification-standard/" target="_blank">Visit website</a>
    </Card>
    <Card title="SLSA" icon="community">
        Supply-chain Levels for Software Artifacts (SLSA) is a security framework, a check-list of standards and controls to prevent tampering, improve integrity, and secure packages and infrastructure.
        <a href="https://slsa.dev/" target="_blank">Visit website</a>
    </Card>
    <Card title="OpenChain Project" icon="community">
        The OpenChain Project identifies key requirements of a quality open source compliance program to build trust in the open source supply chain.
        <a href="https://www.openchainproject.org/" target="_blank">Visit website</a>
    </Card>
</CardGrid>
